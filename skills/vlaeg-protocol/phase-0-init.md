# Phase 0 — Initialization (Mandatory)

**Goal:** project memory and constitution exist before any code is written.

## Before any code or tools
1. Create the project memory files:
   - `task_plan.md` → phases, objectives, checklists
   - `findings.md` → research, discoveries, constraints
   - `progress.md` → what was done, errors, tests, results
2. Create `vlaeg.md` as the Project Constitution:
   - Data schemas
   - Behavioral rules
   - Architectural invariants
3. Halt — do not write scripts in `tools/` until:
   - Discovery Questions (`phase-1-vision.md`) are answered
   - The Data Schema is defined in `vlaeg.md`
   - `task_plan.md` has an approved blueprint

## Done when
`task_plan.md`, `findings.md`, `progress.md`, and `vlaeg.md` exist, and Phase 1 Discovery is complete.
